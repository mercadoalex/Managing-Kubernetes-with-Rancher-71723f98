This lesson covers how Rancher organizes and controls access to cluster resources. You will learn about Rancher projects, namespace management, role-based access control (RBAC), and resource quotas.

<!-- [image] rancher-projects.png - Diagram showing how Rancher projects group namespaces and layer RBAC on top of native Kubernetes -->

## The Rancher RBAC Model

The lesson demonstrates creating projects, assigning users with different permission levels, setting resource limits on namespaces, and understanding how Rancher's RBAC model layers on top of native Kubernetes RBAC.
