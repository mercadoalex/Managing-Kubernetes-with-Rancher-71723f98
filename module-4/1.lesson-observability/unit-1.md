This lesson covers the full observability stack available in Rancher. You will install and configure the Rancher Monitoring chart (Prometheus and Grafana), set up alerting rules, enable centralized logging, and learn how to troubleshoot workloads across clusters.

<!-- [image] rancher-monitoring-stack.png - Diagram of the Prometheus and Grafana monitoring stack deployed by Rancher -->

## From Metrics to Diagnosis

The lesson walks through deploying the monitoring stack via the Rancher UI, creating custom dashboards in Grafana, configuring alert receivers, and using the built-in log exploration tools. It also covers how to correlate metrics, logs, and events to diagnose issues in production.
